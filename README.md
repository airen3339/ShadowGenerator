# ShadowGenerator 影子生成器

## 产品概述

ShadowGenerator 是一款专业的图片阴影生成工具，能够为透明背景的图片自动生成自然、逼真的阴影效果，广泛应用于电商产品图处理、UI设计、游戏素材制作等场景。

## 产品信息

| 项目 | 说明 |
|------|------|
| 产品类型 | 2 |
| 开发语言 | Delphi 12 (VCL) |
| 支持平台 | Windows 7/8/10/11 |
| 许可方式 | 注册码授权 |

## 核心功能

### 1. 阴影生成
- **投影阴影**：生成物体下方的投影效果
- **柔和阴影**：支持阴影边缘模糊，更加自然
- **方向控制**：支持设置光源方向，控制阴影角度
- **透明度调节**：可调节阴影的深浅程度

### 2. 阴影参数
- **偏移距离**：控制阴影与物体的距离
- **模糊半径**：控制阴影边缘的柔和程度
- **阴影颜色**：支持自定义阴影颜色
- **阴影透明度**：精确控制阴影的不透明度

### 3. 批量处理
- **文件夹批处理**：支持整个文件夹批量生成阴影
- **参数记忆**：保存常用参数配置
- **进度显示**：实时显示处理进度和日志

### 4. 图片格式支持
- PNG（支持透明通道，推荐格式）
- BMP
- JPG（输出时自动添加白色背景）

## 使用场景

1. **电商产品图**：为产品白底图添加自然阴影，提升质感
2. **UI设计**：为界面元素添加投影效果
3. **游戏素材**：为角色、道具生成地面阴影
4. **平面设计**：增强图片层次感和立体感

### 试用限制
| 版本 | 限制 |
|------|------|
| 试用版 | 批量处理最多 **200张** 图片，单张处理不限 |

## 技术特点

1. **智能边缘检测**：自动识别透明图片的边缘轮廓
2. **高斯模糊**：采用高质量高斯模糊算法生成柔和阴影
3. **Alpha通道处理**：完美保留原图透明度信息
4. **防破解保护**：内置防调试和代码完整性校验
